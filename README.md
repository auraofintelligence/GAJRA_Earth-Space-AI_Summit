A public, multi-page support-seeking doorway for a proposed Brisbane gathering connecting peaceful space, civic AI, care, community resilience, public evidence and creative participation.

**Public site:** <https://auraofintelligence.github.io/GAJRA_Earth-Space-AI_Summit/>

## Site map

- `index.html` - the proposal and first invitation.
- `vision.html` - why the themes belong in one working commons.
- `themes.html` - seven rooms for early support.
- `program.html` - a draft room-based program and the gaps still needing review.
- `celestial.html` - the Australian eclipse window, source maps and safe-viewing links.
- `support.html` - supporter roles and a browser-local Markdown note builder.
- `related.html` - source lanes, neighbouring work and public/private boundaries.

The site is plain HTML, CSS and JavaScript. Open `index.html` directly or serve the folder with a small static web server; there is no build step.

## Status and boundaries

This is an early proposal, not an announced conference or evidence of venue, funder, partner, cultural authority or government endorsement. Program rooms, dates, speakers, budgets and commitments remain to be confirmed.

Public pages can carry the invitation and source trail. Private contacts, cultural permissions, unreviewed health claims, security-sensitive notes and partner discussions stay outside the repository until the appropriate people approve publication.
